Rebuilding this site

I wanted this website to feel more like a personal technical notebook and less like a collection of experiments.

The new version keeps only the essentials: a short homepage, a blog, a PoC section, and a link to GitHub. The site uses standard Bootstrap components with plain HTML and no custom visual effects.

That makes the site easier to maintain, easier to read, and more appropriate as a public portfolio.
